About

Long-context modeling is growing faster than a single page can hold. The GitHub repository homepage truncates README files above 500 KiB, so paper chapters now live under papers/ while the root README stays a slim hub for News, taxonomy, and navigation. This page is the project homepage: a stable entry point for the curated list and the companion survey.
